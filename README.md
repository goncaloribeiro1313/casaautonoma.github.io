### 📂 UFCD 00629
Esta pasta contém os trabalhos práticos relacionados com o Raspberry Pi.

**Atividades realizadas:**
- Montagem do Raspberry Pi 4.
- Identificação dos componentes.
- Ligação dos equipamentos.
- Preparação e instalação do sistema operativo.
- Registo fotográfico das atividades.

### 🏠 Projeto SmartHome OS – Casa Autónoma
Este projeto consiste no desenvolvimento de uma simulação de uma casa inteligente, utilizando tecnologias web.

**Principais funcionalidades:**
- Controlo da iluminação.
- Monitorização da temperatura.
- Gestão de alarmes e sensores.
- Automatização de dispositivos.
- Interface interativa desenvolvida em HTML, CSS e JavaScript.
