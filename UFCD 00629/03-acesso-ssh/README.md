
Nesta pasta estão guardadas fotografias das atividades práticas realizadas com o Raspberry Pi Connect.O objetivo desta atividade foi aprender a aceder e controlar remotamente o Raspberry Pi através de um navegador de Internet.Durante a atividade, foi utilizada a plataforma Raspberry Pi Connect para visualizar o ambiente de trabalho do Raspberry Pi, aceder ao terminal e executar comandos à distância.Esta ferramenta permite gerir o Raspberry Pi remotamente, sem necessidade de ligar diretamente um monitor, teclado ou rato ao equipamento.
